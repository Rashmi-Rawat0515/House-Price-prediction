# 🏠 House Price Predictor

A Machine Learning web app that predicts California house prices using Random Forest.

## What it does
- Trained on 20,000+ California housing records
- Uses Random Forest Regressor with R² score of 0.80+
- Interactive sliders to adjust house features
- Shows feature importance — what drives prices most

## Tools used
Python, Scikit-learn, Random Forest, Pandas, Seaborn, Streamlit

## How to run
pip install -r requirements.txt
streamlit run app.py
